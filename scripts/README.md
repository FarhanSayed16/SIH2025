# Scripts

Utility scripts for development and testing (PowerShell).

| Script | Purpose |
|--------|--------|
| `check-servers.ps1` | Check if backend/web servers are running |
| `monitor-testing.ps1` | Monitor testing flow |
| `test-complete-flow.ps1` | Run full flow tests |
| `test-endpoints.ps1` | Test API endpoints |

Run from project root, e.g.:

```powershell
.\scripts\check-servers.ps1
.\scripts\test-endpoints.ps1
```
